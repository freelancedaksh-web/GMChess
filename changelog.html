Version History & Updates

v2.0.0 (August 2026) - The Grandmaster Update

  • Engine: Integrated Stockfish 10 WASM via Web Workers to prevent UI thread freezing.
  • Feature: Added 4 dynamic difficulty tiers (Beginner, Club, Master, GM) mapping to Stockfish skill levels 0-20 and depths 5-18.
  • Feature: Implemented 0-latency Web Audio API synthesizers for piece movement, captures, and checks (no external MP3s required).
  • UI/UX: Introduced 4 real-time switchable color themes (Retro, Wood, Neon, Dark) using CSS root variables.
  • QoL: Added "Undo Move" functionality for both local and AI game modes.
  • Infrastructure: Implemented real-time visitor tracking via CounterAPI.

v1.0.0 (Initial Release)

  • Core: Established 0-bug standard FIDE move validation using chess.js (v0.10.3).
  • Feature: Algebraic typing (Blitz mode) input parser for keyboard-only play.
  • UI/UX: Windows 98 aesthetic interface with grid-based board rendering.
  • QoL: Real-time engine evaluation bar and PGN (Portable Game Notation) export functionality.
